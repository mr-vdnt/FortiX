# FortiX Final Submission Package

This directory is structured exactly for your academic submission.

1. **source/**: Contains the frozen v1.0.0-rc.1 source code (Node.js, React, Playwright tests).
2. **documentation/**: Contains all Markdown reports, defense scripts, and release notes. 
   -> *Action:* Convert `FINAL_ACADEMIC_REPORT.md` to Word/PDF and place here.
3. **evidence/**: Placeholder directories for you to drop in your final screenshots, PDF verification reports, and terminal test logs.
4. **deployment/**: Contains your Docker configuration for reproducible grading.

Good luck on your defense!
